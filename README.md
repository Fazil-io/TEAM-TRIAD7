# TRIAD7 — SAMARTH Platform
### Smart India Hackathon 2026 | Problem Statement ID: SIH26136

Official team and project portfolio website for **Team TRIAD7** presenting **SAMARTH** — a digital innovation-procurement platform connecting government challenges with startup solutions for evaluation, piloting, milestone-based funding, validation, procurement, and scale-up.

---

## 🏛️ Problem Statement Details

- **Problem Statement ID:** SIH26136
- **Problem Statement:** Startup friendly public procurement mechanism that enables government departments to identify, pilot, procure, and scale innovative solutions from eligible startups.
- **Category:** Software
- **Theme:** Miscellaneous
- **Nodal Organization:** Government of Maharashtra – Maharashtra State Innovation Society (MSInS), Department of Skills, Employment, Entrepreneurship and Innovation
- **Our Solution:** **SAMARTH** (Government–Startup Innovation Procurement Platform)

---

## 🚀 Key Website Features

1. **Sticky Header & Brand Wordmark:**
   - Blurred glassmorphic header transitioning on scroll with active section detection and mobile hamburger navigation.
2. **Hero Section:**
   - SIH 2026 badge, official typography, dynamic interactive ecosystem visual (Government → Challenge → Startup → Evaluation → Pilot → Validation → Procurement → Scale).
3. **Credibility & Trust Strip:**
   - Prominent track credentials (SIH 2026, PS ID 26136, Software, Govt of Maharashtra, MSInS).
4. **Special Visual Element — Innovation Pipeline:**
   - Interactive 8-stage glowing pathway with auto-play mode and manual phase inspection.
5. **The Gap We Identified (Problem Analysis):**
   - Side-by-side comparison of Public Sector Demand vs Startup Supply with central missing link ("THE GAP") and root-cause analysis.
6. **Introducing SAMARTH (8-Stage Workflow):**
   - Interactive horizontal pipeline with clickable stage cards revealing deliverables, stakeholders, and KPI gates.
7. **From Problem to Impact (12-Step Governance):**
   - Visual flow diagram tracking operational steps from challenge authoring down to statewide rollout.
8. **What Makes SAMARTH Different (Innovation):**
   - 4 premium cards: Smart Matching, Pilot-First Validation, End-to-End Pipeline, Transparent Decision Tracking.
9. **Technology Behind SAMARTH (5-Layer Architecture):**
   - Interactive layer inspector covering Users, Web Portals, Backend Microservices, Data & Audit, and Cloud & Integrations.
10. **Smart Problem–Startup Matching:**
    - Algorithm flowchart + 3 simulated candidate startup cards with match scores and verified eligibility badges (clearly marked **DEMO DATA**).
11. **From Proposal to Proof (Pilot & Validation):**
    - Controlled sandbox lifecycle and milestone-based funding structure (30% - 40% - 30% tranche releases).
12. **Designed for Measurable Impact:**
    - 5 impact pillars + tri-party ecosystem visual (Government ↔ SAMARTH ↔ Startups).
13. **Feasibility & Viability Analysis:**
    - Comprehensive side-by-side matrices detailing technical feasibility and economic sustainability.
14. **Potential Market Opportunity (TAM / SAM / SOM):**
    - Sizing funnel: TAM ₹5,000 Cr (India-wide), SAM ₹500 Cr (Maharashtra), SOM ₹50 Cr (Initial sandbox) with disclaimer.
15. **Explore the SAMARTH Prototype (Live Interactive Console):**
    - In-page mock dashboard + full modal console supporting 6 functional tabs (Challenges, Applications, Evaluations, Active Pilots, Milestone Escrow, GeM Scale-Up).
16. **Meet TRIAD7 (Team Cards):**
    - Easily customizable team member cards with role badges, skills, bios, GitHub, and LinkedIn links in `src/data/team.ts`.
17. **Why TRIAD7? (Team Identity):**
    - Subtle animated geometric logo treatment (triad triangle nodes + 7 motif) and philosophy.
18. **Research & Ecosystem:**
    - Regulatory alignments with Startup India / DPIIT, GeM, CPPP, and Maha-eProcurement.
19. **Final Call-to-Action & Comprehensive Footer:**
    - Direct actions to explore SAMARTH or connect with the team, with public sector disclaimers.

## 🛠️ How to Customize Team Members

Team member information is cleanly separated in `src/data/team.ts`. Simply edit the `teamMembers` array with your actual names, roles, bios, and links.

## 💻 Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS + Vanilla CSS utilities
- **Icons:** Lucide React + custom SVG brand icons
- **Animations:** CSS keyframe glow loops & interactive state transitions
